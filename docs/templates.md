## Which engine?

All four templates compile with **pdfLaTeX**, the default on Overleaf and in VS Code with LaTeX Workshop. The paper template uses BibTeX, which both handle automatically.

!!! info "Overleaf buttons"
    The *Open in Overleaf* buttons work from the published site. Overleaf will ask you to sign in, then create a new project from the ZIP.
