\section*{Question 1}
Write the question here, or paste only the part you need.

\subsection*{Solution}
Suppose
\begin{equation}
    y_i = \alpha + \beta x_i + \varepsilon_i,
    \qquad i=1,\ldots,n.
\end{equation}

A useful aligned derivation is
\begin{align}
    \E[y_i\mid x_i]
        &= \E[\alpha + \beta x_i + \varepsilon_i \mid x_i] \\
        &= \alpha + \beta x_i + \E[\varepsilon_i\mid x_i].
\end{align}

Therefore, if $\E[\varepsilon_i\mid x_i]=0$,
\[
    \E[y_i\mid x_i] = \alpha + \beta x_i.
\]
