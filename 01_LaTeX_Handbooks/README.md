# 01 · Handbooks

Two long reference documents. Read the PDF; edit the `.tex`.

| File | Pages | Read it when |
|---|---|---|
| `LaTeX_Beginner_Handbook` | 110 | You are learning LaTeX from zero. 15 parts: how LaTeX works, text, math, equations, small layout commands, tables, figures, citations, paper patterns, debugging, quick reference. |
| `LaTeX_Preamble_and_Setup_Guide` | 22 | You want to configure a document: packages, fonts, margins, bibliography, theorem environments, and ready-to-copy preambles for homework, empirical papers and theory papers. |

**Tip:** the handbook shows most examples as *source code next to compiled result*. Search the PDF (Ctrl/Cmd+F) for a command name to jump to its explanation.

Both files use `pdfLaTeX` and the standard packages listed in their preambles.
