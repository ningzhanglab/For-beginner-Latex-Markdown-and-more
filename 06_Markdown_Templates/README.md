# Markdown Templates

These templates are meant to be copied and renamed.

| Template | Use it for |
|---|---|
| `Markdown_Template_01_Minimal_Note.md` | A very simple note |
| `Markdown_Template_02_Research_Notes.md` | Daily research notes or project logs |
| `Markdown_Template_03_Project_README.md` | A GitHub or research-project README |

Open any `.md` file in VS Code or GitHub and start replacing the example text.
