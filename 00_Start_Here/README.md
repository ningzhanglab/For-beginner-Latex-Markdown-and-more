# 00 · Start Here

One file, one job: confirm that LaTeX works on your computer or in your editor.

| File | What it is |
|---|---|
| `LaTeX_Installation_Test.tex` | A one-page document that uses only standard LaTeX (no extra packages). |
| `LaTeX_Installation_Test.pdf` | What the compiled result should look like. |

**Try it:** compile the `.tex` file. If you get a PDF that looks like the reference PDF, your setup works. If not, see the [Setup Guide](../SETUP_GUIDE.md) (section 9 covers missing packages, section 11 covers editor problems).
